# Learning Natural Language Processing

In this project are files I worked on while following the O'Reilly course "Natural Language Processing" from Pearson.

The course is located on the [O'Reilly Safari learning platform](https://learning.oreilly.com/course/natural-language-processing/9780135258842/).

## Getting Started

Set up a local virtual environment:

```
python -m venv ./env
source bin/activate
```

Install the packages:

```
pip install -r requirements.txt
```

Start the notebook server:

```
jupyter notebook
```
